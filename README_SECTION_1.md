# AI for SA & Programmers — OGA INTERNATIONAL Co., Ltd.

## Section 1 checkpoint

This package contains slides 1–36 of the bilingual training presentation for **OGA INTERNATIONAL Co., Ltd., Business Solution Department**. It covers AI foundations for System Analysts, client discovery, requirement analysis, proposal preparation, corporate document control, ISO 9001, ISO 29001, SOPs, work instructions, records, checklists, confidentiality, and human approval.

## Typography verification

The deck embeds **TH SarabunPSK** font files in `assets/fonts/`:

- `THSarabunPSK-Regular.ttf` — regular weight for body text and Thai explanations.
- `THSarabunPSK-Bold.ttf` — bold weight for cover/title/main headings and English section labels.

The HTML pages use the family declaration `TH SarabunPSK` with the embedded files as the first font source. The cover was adjusted to 26 pt bold for the primary title and 16 pt regular for the Thai explanatory subtitle. Main headings are 20 pt bold and body text is 16 pt regular or larger where visual hierarchy requires it.

## Bilingual verification

Each authored slide uses English as the primary instructional language and Thai as the explanatory language. English/Thai title pairs use the pattern `English / ภาษาไทย`, while content blocks place the Thai explanation directly below or beside the English instruction.

## Important note

This session creates the presentation in HTML mode. A native editable PowerPoint (`.pptx`) deck is not generated in this session. The full 80-slide deck remains in progress; this ZIP is the completed Section 1 checkpoint.

## Source

The embedded TH SarabunPSK font files were obtained from the public SarabunConsortium TH-Sarabun-PSK repository and are included for portability.
